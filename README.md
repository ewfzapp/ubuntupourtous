# 🐧 Ubuntu Pour Tous

> Le guide Ubuntu le plus bienveillant du web français.

**ubuntupourtous.org** — Apprendre Linux simplement, pas à pas, avec des captures d'écran à chaque étape et des quiz de validation.

## Pour qui ?
- 👴 Seniors
- 🎓 Étudiants  
- 🦠 Victimes de virus
- 😤 Déçus de Windows/Mac

## Stack
- Next.js 15 (export statique)
- GitHub Pages + Cloudflare
- TypeScript + Tailwind CSS
